# Scheduling a training block

Open **Today → Training calendar → Scheduling assistant**. You can also use
**Move block workouts** on a planned or missed block appointment. The ordinary
appointment editor links to the assistant when you want to move later sessions.

Choose an active block and one of these actions:

- **Move a workout:** select the session, a new date, and either only that workout
  or that workout and later sessions. The first workout uses the new date;
  later sessions follow the selected training days, in block order.
- **Change training days / schedule remaining sessions:** choose a start date and
  any one to seven weekdays. The number of training days changes the dates, not
  the workouts, rounds, progression, or original programme settings. This works
  after the block has started and for blocks with no appointments yet.
- **Clear future dates:** remove the block's eligible appointments from the chosen
  date onward. Sessions remain available in the block. This does not skip them or
  end the block, and you can rebuild their dates later.

Include missed sessions to catch up outstanding workouts in the selected scope.
Untick it to leave past appointments for separate action. Completed, skipped and
in-progress sessions are excluded. Other blocks, unrelated workouts and explicit
rest appointments are preserved.

When a proposed date conflicts with an existing workout or rest day, choose to
use the next available training day or explicitly allow the overlap. Conflicts
block confirmation until you make a choice. Review the old and proposed dates
before applying; cancelling the assistant writes nothing. Existing block
appointments are moved instead of duplicated. Selected weekdays are retained
with calendar data and included in backups.

**Undo scheduling change** restores the previous calendar while Today remains
open, provided no later calendar change or change of active workout has occurred.
It is not a persistent version history. The usual local-save status remains the
confirmation that the calendar was saved on this device.

Weekly recurring appointments linked to a block are not supported by the
assistant; edit those separately. Normal block scheduling creates explicit
appointments, one per unresolved session. The existing block-manager scheduler
remains available; its weekday count follows the original programme settings.
