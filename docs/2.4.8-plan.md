## User corrections

The user found the separate classification selector and delete control crowded the workout screen. Restore short taps on the set-number marker to cycle Working → Warmup → Deload → Working. Holding an unfinished set number arms deletion on the separate tick; tapping that red delete tick removes the set, with no additional modal. Holding/releasing alone never deletes or changes classification. Completed sets cannot be armed for deletion. Tapping the armed number again or Escape cancels. Keyboard Enter/Space cycles classification; Delete/Backspace arms deletion. Pointer cancellation and unmount clear gesture timers.

The user clarified that the weight-increase icon belongs next to the rotating change-exercise arrows inside each exercise card, beside the robot/history/instructions toolbar, NOT next to the session-wide Adapt this workout action. Each resistance card now has a 44px icon control showing a dumbbell crossed by a red rising line. Its accessible label and tooltip identify Increase weight or Reduce assistance and its exercise. It opens the existing exercise-specific preview and is disabled without unfinished working sets. Cardio has no icon. Remove the space-consuming text button below the suggestion disclosure. No exercise picker or automatic exercise selection is needed.

Keep literal previous-set copying with source labels. Retain the previous release's readable completed values, compact header, progression qualification, manual preview protection, number-pad dialogs and discard confirmation.
